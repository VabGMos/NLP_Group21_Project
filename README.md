# NLP Group 21 project

The project is organized into three project-work folders and a shared Python
package:

```text
project_1/             Cross-validation notebook
project_2/             Reserved for project work 2
project_3/             Reserved for project work 3
src/nlp_group21_project/   Shared data, encoding, model, and evaluation code
```

## Setup

Install [uv](https://docs.astral.sh/uv/) and, from the repository root, run:

```powershell
uv sync
```

Open `project_1/cv_v2.ipynb` in VS Code and select the project's `.venv`
Python environment as the notebook kernel. The editable package installed by
`uv sync` makes the shared code available from each project folder.

The notebook downloads SNLI and the MPNet sentence-transformer model on first
use. Its full cross-validation and final training run require substantial time
and memory; a GPU is recommended. Saved notebook outputs are from the earlier
run and are not regenerated by the reorganization.
